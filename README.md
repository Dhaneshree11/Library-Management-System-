# 📚 Library Management System (Java)

## 🚀 Overview
A console-based Library Management System developed using Core Java and Object-Oriented Programming principles. This project simulates real-world library operations like book management, search, and issue/return system.

---




## 🛠️ Features
- Add new books
- Search books by Serial Number
- Search books by Author Name
- Upgrade book quantity
- Issue (Check-Out) book
- Return (Check-In) book
- Display all books

---

## 🧠 Concepts Used
- Object-Oriented Programming (OOP)
- Encapsulation
- Arrays
- Input validation
- Menu-driven application

---

## 🏗️ Project Structure
- `Book.java` → Handles book details
- `Library.java` → Manages book operations
- `LibraryManagementSystem.java` → Main execution file

---

## ▶️ How to Run
1. Clone the repository
2. Open in any Java IDE (Eclipse / IntelliJ)
3. Run `LibraryManagementSystem.java`
